# This mini project let the user to predict 3 gestures : idle , wave right and wave left that are depending on the mpu6050 6 sensors axes data.


The model was built on behalf of Google Colab with neural networks.

For the dataset , it wasn't recorded , but preprocessed from an exisiting dataset found on the link below as 400 samples were taken from each label:

    https://www.kaggle.com/datasets/dilharajayawardhane/6-axis-motion-gesture-dataset-hand-waves-and-flicks

The model was then deployed on Esp32 MCU on behalf of edge impulse.
